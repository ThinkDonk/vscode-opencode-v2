# OpenCode artwork

The extension icon and themed button/terminal icons use the OpenCode mark.

Sources:
- [OpenCode brand assets](https://opencode.ai/brand)
- [Official extension artwork](https://github.com/anomalyco/opencode/tree/dev/sdks/vscode/images), backed by `packages/identity/mark.svg`
- [Logo mark geometry](https://github.com/anomalyco/opencode/blob/dev/packages/ui/src/components/logo.tsx)

`icon.png` is rendered at 256 × 256 from the official mark. The two SVG icons use the same mark geometry, scaled to a 16 × 16 canvas and colored for VS Code's light and dark themes.

This is an unofficial community extension; using the artwork does not imply endorsement.
